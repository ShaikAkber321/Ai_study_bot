# AI Study Buddy 🤖📘

AI Study Buddy is a GenAI-powered web application designed to help students understand academic concepts easily and practice through automatically generated quizzes.

---

## 🚀 Problem Statement
Students often struggle to clearly understand concepts and lack instant doubt-solving support. Traditional learning resources are not interactive or personalized.

---

## 💡 Solution
AI Study Buddy acts as a personal learning assistant that:
- Explains concepts in simple language
- Generates multiple-choice quizzes for practice
- Encourages active and self-paced learning

---

## ✨ Features
- 📖 Concept explanation in simple words
- 📝 Automatic MCQ quiz generation
- ⚡ Fast AI responses
- 🎨 Clean and student-friendly UI
- 🌐 Web-based application

---

## 🛠 Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** Python (Flask)
- **AI Model:** Groq LLaMA 3.1 (Instant)
- **API:** Groq API
